# Nearby Radar — نسخه وب

## اجرا
1. فایل‌ها را روی یک هاست استاتیک با HTTPS منتشر کنید (مثلاً GitHub Pages یا Netlify).
2. آدرس سایت را با Chrome به‌روز روی گوشی اندرویدی باز کنید.
3. از منوی Chrome گزینه «Add to Home screen» یا «Install app» را بزنید.
4. برای اسکن، دکمه «شروع اسکن بلوتوث» را لمس کنید و مجوز را بدهید.

## محدودیت‌های مهم
- Web Bluetooth فقط در مرورگرهای سازگار و در بستر امن HTTPS کار می‌کند.
- اسکن پیوسته تبلیغات BLE با `requestLEScan` هنوز در همه نسخه‌های Chrome/Android در دسترس نیست؛ در صورت نبود آن، برنامه از انتخاب‌گر استاندارد دستگاه‌های بلوتوث استفاده می‌کند.
- مرورگر وب API عمومی برای فهرست‌کردن شبکه‌های Wi-Fi اطراف، اسکن همه هات‌اسپات‌ها یا کشف فهرست Quick Share ندارد.
- شناسه بلوتوث ممکن است شناسه‌ای خصوصی/موقت باشد و الزاماً MAC واقعی دستگاه نیست.
